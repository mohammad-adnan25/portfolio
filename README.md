# Mohammed Abdullah Adnan | Portfolio

Personal portfolio website of a B.Tech Computer Science graduate and software developer.

**Live site:** https://mohammad-adnan25.github.io/portfolio/

## Features
- Animated entry screen and curved page-transition effects
- Project sections with a short brief and an animated demo for each
- Credentials section with viewable certificates
- Responsive design, with reduced-motion support
- Direct Gmail, LinkedIn and GitHub buttons

## Projects featured
- Feedback Analysis System (Python, Flask, MySQL), a TCS iON industry project
- Smart Mirror (Raspberry Pi, Python, Firebase, MagicMirror2)
- Recipe Sharing Platform (MongoDB, Express.js, React.js, Node.js)

## Built with
HTML, CSS and vanilla JavaScript in a single `index.html` file, hosted on GitHub Pages.
